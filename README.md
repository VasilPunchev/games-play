
# Games Play

Games Play is a React application for browsing and managing games.

## Technologies

- React
- Vite
- React Router
- Fetch API
- SoftUni Practice Server

## Implemented

- Home page with the latest 3 games
- Catalog with all games
- Game Details page
- Login
- Register
- Add Game
- Delete Game
- Nested Routes
- AbortController
- Authentication with access token
- Form validation with `window.alert`

## Routes

- `/` - Home
- `/catalog` - Catalog
- `/games/:gameId` - Details
- `/games/:gameId/edit` - Edit Game
- `/login` - Login
- `/register` - Register
- `/create` - Add Game
